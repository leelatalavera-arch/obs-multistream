Multistream for OBS - Linux
===========================

Option A (Ubuntu 24.04 or newer): install the .deb
  OBS must come from the official OBS PPA (Ubuntu's own OBS is too old):
      sudo add-apt-repository ppa:obsproject/obs-studio
      sudo apt install obs-studio
  Then:
      sudo apt install ./obs-multistream-*.deb
  Remove it later with:
      sudo apt remove obs-multistream

Option B (any distro, no sudo): this .tar.gz
  1. Close OBS.
  2. Open a terminal in this folder and run:   ./install.sh
  3. Start OBS. The Multistream dock opens the first time
     (later: Docks > Multistream).
  Remove it later with:   ./uninstall.sh

Needs OBS 31.0 or newer, installed from your distro or the official OBS PPA
(not the Flatpak; Flatpak OBS only loads plugins packaged as Flatpak
extensions).
